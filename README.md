# Poppy

반려견의 사진 또는 짧은 영상을 바탕으로 관찰 가능한 행동 신호와 상황 정보를 분석해 현재 감정·상태와 욕구를 추정하는 웹 프로토타입입니다.

## 현재 상태

기본 웹 앱과 주요 기능 구현은 완료되어 있으며, 실제 브라우저 실행까지 확인했습니다.

현재 마무리 단계에서 아래 항목을 검증·보완하고 있습니다.

- 강아지 개별 특성 저장 흐름 최종 검증
- 강아지 정보/특성 자동수정 기능
- OpenAI API 실제 연동 및 분석 전체 흐름 검증

## 주요 기능

- 회원가입 / 로그인
- 여러 강아지 프로필 등록 및 관리
- 이름, 생년월일, 견종, 성별, 중성화 여부, 평소 성격 저장
- 강아지 개별 특성 저장
  - 프리셋 특성 추가
  - 직접 입력
- 사진 분석
- 30초 이하 영상 분석
- 영상에서 FFmpeg로 대표 프레임 추출
- 강아지 프로필, 개별 특성, 현재 상황을 AI 분석 컨텍스트에 반영
- 감정·상태 및 현재 욕구/의도 분석
- 분석 결과 및 이력 저장
- 분석 결과에 대한 맞음 / 아님 피드백

## 분석 방식

등록된 강아지는 현재 입력뿐 아니라 저장된 프로필과 개별 특성을 함께 참고합니다.

분석 시에는 현재 관찰 행동을 가장 중요하게 보고, 개별 특성·현재 상황·일반적인 개 행동 지식·견종 정보를 보조적으로 사용합니다.

영상은 OpenAI API에 직접 전달하지 않고 FFmpeg로 대표 프레임을 추출한 뒤 이미지 입력으로 분석합니다.
